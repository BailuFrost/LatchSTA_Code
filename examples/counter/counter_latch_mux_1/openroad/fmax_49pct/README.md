# 后布线最高频率估算与 STA 复核（两相各 49%）

> 已补充 [1.73 ns 后布线功耗报告](../power_1p73ns/README.md)：连续计数平均功耗 570.835 µW，每周期能量 0.987545 pJ，另含 50% 使能和保持场景。

**在当前 I/O 预算下，常规后布线 STA 的最高频率约为 578.12 MHz，临界周期约为 1.72974 ns。** 实际重跑：1.7298 ns 通过，1.7297 ns 出现一条输出 setup 违例。

**若同时要求全部锁存器 GATE 端的两相时钟严格非重叠，则当前时钟树和 49% 占空比给出的名义频率上限约为 431.20 MHz。** 补跑的 2.32 ns / 431.03 MHz 同时通过常规 STA 和 TT 名义非重叠检查，但非重叠裕量仅约 0.009 ps，不能视作有工程余量的工作点。

这里的频率指 phi1、phi2 各自的重复频率，也是使能时完整两相计数周期的频率。两个结论均限定于现有布线、SKY130 HD TT / 25°C / 1.8 V、nominal RC 和当前外部时序预算，不代表多角签核最高频率。

## 1. 从 1.75 ns 报告估算

原始 [输出 setup 报告](../sta_1p75ns_49pct/reports/openroad/output_setup.rpt) 中的最差路径是：

`phi2 → state_phi2_bit0/GATE → state_phi2_bit0/Q → count[0]`

在 T = 1.75 ns 时，到达时间 1.546190 ns，要求时间 1.566250 ns，slack 为 +0.020060 ns。保持原有 1.00 ns 输出预算、0.05 ns uncertainty 及其余所有外部约束不变，只缩放两相时钟边沿：

- phi1 高电平窗口：0.005T ～ 0.495T。
- phi2 高电平窗口：0.505T ～ 0.995T。
- 输出路径发射参考为 phi2 上升沿 0.505T，捕获参考为下一周期 phi1 下降沿 1.495T，两者间隔为 0.99T。

因此该路径的近似 slack 为：

```text
S(T) = 0.020060 + 0.99 × (T − 1.75) ns
Tmin = 1.75 − 0.020060 / 0.99 = 1.72973737 ns
fmax = 1000 / Tmin = 578.12245 MHz
```

不能直接把全局 setup WNS = 0 当作极限；该设计存在合法 latch 时间借用，部分路径 slack 为 0 且标记 MET。也不能对两相路径统一套用单周期寄存器公式 T − slack，必须使用实际发射/捕获边沿关系。

## 3. 为什么非重叠会给出更低的上限

从传播时钟报告得到，phi1 最晚关闭延迟 0.279602 ns，phi2 最早开启延迟 0.256411 ns。保持 49% 占空比时，端口交接死区只有 0.01T，因而全部 latch GATE 端的保守包络间隔为：

```text
gap12(T) = 0.01T + 0.256411 − 0.279602
         = 0.01T − 0.023191 ns
gap12 > 0  ⇒  T > 2.3191 ns，f < 431.20176 MHz

gap21(T) = 0.01T + 0.261666 − 0.276296
         = 0.01T − 0.014630 ns
```

第一方向限制更强。在 2.32 ns 时，两方向间隔分别为 +0.000009 ns 和 +0.008571 ns，详见 [非重叠报告](T2p32ns/clock_nonoverlap.rpt)。这是所有同相 latch GATE 端构成的保守时钟包络，使用保留 6 位小数的时钟延迟，未额外扣除抖动或差分时钟不确定度。常规 STA 中的 0.05 ns uncertainty 继续保留；不能把它视为此包络检查已经包含的非重叠保护量。

**所以 578.12 MHz 是当前约束下的 STA 极限，不能据此宣称电路在该频率满足严格两相非重叠要求。** 若要在接近该频率满足非重叠，需要另行调整占空比/死区或时钟树，然后重新 STA；本次按原 49% 占空比分析。
