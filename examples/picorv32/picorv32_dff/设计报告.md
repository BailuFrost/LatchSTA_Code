此外，最终日志存在 `sky130_ef_sc_hd__decap_12` 无 Liberty 的警告和 Qt Wayland 插件警告；它们没有阻止本次提取、最终报告和版图图像生成。日志中未见该 decap 单元的实例面积分类，不能将该警告自动解释为功能单元缺失。

后续 latch 与本 DFF 基线比较时，应保持同一 CPU 参数、Liberty/PVT、RC 提取规则、I/O 预算、工具版本和报告阶段。单时钟与双相 latch 时钟应在相同体系结构周期下比较，并明确双相相位、占空比、死区和不确定度；仅比较两个时钟名称的频率不足以说明吞吐率相同。

物理比较应预先选定相同 core 面积，或相同初始利用率的实验口径，并同时报告实际 core 面积、非 filler 单元面积及 CTS/门控/hold 修复开销。功耗比较应使用相同程序、存储器响应、复位条件、统计窗口和活动率数据，同时计入 latch 双相时钟的生成与分发开销。对 Fmax 的比较应增加周期扫描及对应的 setup/hold 检查，避免把单次 STA 的外推值当作已验证工作频率。
